Core REST Endpoints Overview

GET /api/cars - List all cars (supports filters)
POST /api/cars - Add new car to fleet
GET /api/cars/available - List currently available cars
POST /api/bookings - Create a car booking reservation
PATCH /api/bookings/{id}/start - Hand over car / mark ACTIVE
POST /api/bookings/{id}/return - Process return & finalize billing
PATCH /api/bookings/{id}/cancel - Cancel booking and release car
GET /api/dashboard/stats - Fleet utilization & revenue KPIs
